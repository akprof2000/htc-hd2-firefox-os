# Сборочные скрипты из домашней папки WSL

Рабочие скрипты, которыми собирались gonk, Gecko 44 и Gaia 2.5 в WSL (Ubuntu 24.04).
Сохранены как есть, пути в них — от домашней папки (`~/gonk`, `~/gecko-b2g-b2g44_v2_5`,
`~/gaia25`, `~/android-ndk-r8e`, `~/py27`). Основные: `build44.sh`, `conf44.sh`, `mozconfig44`
(Gecko 44), `getgonk.sh`, `mkgonk.sh` (gonk), `py27.sh` (Python 2.7 для сборки), `fix*.sh` —
правки, без которых старый код не собирается свежим тулчейном.
